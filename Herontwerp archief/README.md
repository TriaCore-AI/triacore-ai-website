# Herontwerp — nieuwe TriaCore homepage (experience)

Deze map is losgekoppeld van de live site (`src/`). Hier verzamelen we research en de creatieve
briefing voor een herontwerp van de homepage — meer een *experience*, nog steeds overzichtelijk.
Er wordt pas gebouwd nadat deze briefing is goedgekeurd, en dan als zelfstandig prototype in deze
map. De bestaande site verandert hierdoor niet.
